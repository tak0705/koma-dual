# コマ・デュエル（koma-duel）

大・中・小のコマで相手のコマを**上書き**できる、進化版の三目並べ。
3×3のマスで、**一番上のコマ**が縦・横・斜めに3つ揃ったら勝ちです。

- 1台で遊ぶ（CPU対戦／2人対戦）
- 遠くの相手と遊ぶ（**サーバー不要のリンク対戦**、任意で部屋コード対戦）
- iPhone Safari のホーム画面に追加すると全画面アプリのように動きます（PWA）

外部の有料サービスは使っていません。**GitHub Pages にそのまま置けば動きます**（ビルド不要・完全静的）。

---

## ルール

| コマ | 数 | できること |
| --- | --- | --- |
| 大 | 2個 | 小・中を上書きできる。大の上には何も置けない |
| 中 | 2個 | 小を上書きできる |
| 小 | 2個 | 空きマスにしか置けない（上書きできない） |

各プレイヤーは大・中・小を2個ずつ、計6個。

手番にできることは、次のどちらか1つです。

1. **手持ちのコマを置く** — 空きマス、または**自分より小さいコマの上**。
2. **盤上のコマを動かす** — 一番上にある自分のコマを、空きマスか小さいコマの上へ。

### 自爆（重要なルール）

自分のコマを持ち上げたとき、**下から出てきた相手のコマで相手が3つ揃ったら、その場で相手の勝ち**です。
動かす前に、下に何が隠れているか確かめましょう。

（自分のライン完成と相手のライン露出が同時に起きた場合は、指した側の勝ちとします。）

## 遊び方

`index.html` をブラウザで開くだけで動きます（ローカルなら `python3 -m http.server` などで配信）。
ホーム画面に追加すると、アドレスバーの無い全画面で遊べます。

### 3つのモード

| モード | 内容 |
| --- | --- |
| 🤖 CPUと対戦 | ピッコロAI。**初級**（ランダム寄り）／**中級**（1手読み＋阻止）／**上級**（反復深化ミニマックス＋αβ枝刈り） |
| 👥 2人で対戦 | 同じスマホをはさんで交互にタップ（パス＆プレイ） |
| 🔗 リンクで対戦 | 1手ごとに局面をリンクにしてLINEなどで送る**非同期オンライン対戦**。サーバー不要 |

#### リンク対戦の流れ

1. 「先手で対局をはじめる」→ 1手指す
2. 出てくるリンクを「コピー」または「LINEなどで送る」で相手へ送る
3. 相手がリンクを開くと、その局面から続きを指せる（相手が指すと、またリンクが出る）
4. 以降はリンクを送り合うだけ。盤面と手番はリンク自体に入っているので、サーバーもログインも不要

> リンクには盤面と手番だけが入ります（個人情報は含みません）。長さは40文字程度です。

### 部屋コード対戦（任意・APIがあるときだけ）

`api/room.js` が動く環境（Vercel など）に置くと、部屋コードで自動同期する対戦も使えます。
GitHub Pages では API が無いため、この欄は「使えません」と表示され、リンク対戦にフォールバックします。

## ファイル構成

```
index.html            画面（メニュー／盤面／ルール／結果）
style.css             デザイン・アニメーション
app.js                画面の制御（モード、操作、共有リンク、効果音）
logic.js              ゲームのルール（合法手・勝敗・自爆判定・状態のシリアライズ）
ai.js                 ピッコロAI（3段階・αβ探索）
manifest.json         PWA 設定
sw.js                 Service Worker（オフライン対応）
icons/                アプリアイコン（PNG/SVG と生成スクリプト）
api/room.js           部屋コード同期API（Vercel用・任意）
tests/logic.tests.js  ユニットテスト本体
tests/run_tests.py    Node が無い環境向けのテスト実行（QuickJS）
tests/tests.html      ブラウザでテストを走らせるページ
```

すべて相対パスで書いてあるので、`https://<user>.github.io/koma-duel/` のようなサブパスでもそのまま動きます。

## テスト

ゲームロジックとAIのユニットテストが38件あります。**Node が無くても実行できます。**

```bash
# 1) Node がある場合
node tests/logic.tests.js

# 2) Node が無い場合（Python + QuickJS。本物のJSエンジンで同じテストを実行）
pip install quickjs
python3 tests/run_tests.py
```

ブラウザで見たいときは `tests/tests.html` を開いてください。

テストしている内容（38件）:

- 初期状態・手持ちの計算（盤面から逆算）
- 上書き制限（同サイズ不可・小の上に中/大は可）
- 移動（一番上のコマだけ・移動先の制限・下のコマが出る）
- 勝敗判定（置き・上書き・斜め・混在ライン）
- **自爆**：持ち上げた下から相手のラインが出た場合
- 同時成立時の優先順位
- 状態のシリアライズ（往復・短さ・壊れたコードの拒否・リンクを挟んだ1局の再現）
- AI（全レベルの合法手・即勝ち・阻止・2手詰み・αβ探索と素のミニマックスの一致）

## 公開方法

### GitHub Pages（いちばん簡単・完全無料）

1. このフォルダをリポジトリに入れて `main` に push
2. リポジトリの **Settings → Pages** で Source を「Deploy from a branch」、Branch を `main` / `/ (root)`
3. `https://<user>.github.io/<repo>/` で公開されます（`api/room.js` は無視されます）

### Vercel

1. リポジトリを Vercel に import（フレームワークは Other、ビルドコマンドなし）
2. そのままデプロイすると `api/room.js` も含めて公開されます
3. 部屋コード同期を使いたいときはメニューの「部屋コードで対戦」から

> 部屋コードはメモリ上の保存なので、サーバーレスのコールドスタートや複数インスタンスでは消えることがあります。
> 確実に遊ぶならリンク対戦を使ってください。

## メモ

- 効果音は Web Audio API。右上の `♪` でオン／オフ（設定は端末に保存）。
- 「待った」はCPU戦では自分の手番まで戻します（AIの手も取り消し）。
- 対局は自動で保存され、メニューの「前回の続きから」で再開できます。
- 個人情報（本名・勤務先・連絡先など）は一切含んでいません。
